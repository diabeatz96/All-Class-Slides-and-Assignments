The Code Carnival

Step right up! Three booths, one afternoon, all the tickets you can earn.

How every booth works

  1. Open the csc436-code-carnival folder in VS Code. Leave npm run dev running in the terminal.
  2. Each booth below names the file to open. Inside it, search (Cmd/Ctrl+F) for TODO BRONZE, then TODO SILVER, then TODO GOLD.
  3. Edit and save. The browser updates by itself. No refresh needed.
  4. To uncomment a line, select it and press Cmd+/ (Mac) or Ctrl+/ (Windows).
  5. Page blank or nothing happens? Open the Console: Cmd+Option+J (Mac) or Ctrl+Shift+J (Windows). Red text gives the file and line number.
  6. Every booth has a "Stuck?" section with docs links. Pros live in the docs. So will you today.
