Bronze: Tailwind CSS (1 ticket each)

Tailwind gives you tiny classes that each do one thing. You build a look by stacking them. The left card is done. The right card has no classes yet. Make it look like a prize.

  1. Find the TODO BRONZE comment in index.html. The plain card is right below it.
  2. Add a class="..." to the outer <div> with at least one class from every row of the cheat sheet.
  3. Style the three text lines inside it too: give the <h3> a size and weight, like text-2xl font-bold.

Done when: your card has a background color, padding, rounded corners, a shadow, styled text, and it grows or tilts when you hover over it. It must not look like a copy of the red example.

Silver: DaisyUI (2 tickets each)

DaisyUI turns one class into a whole component. class="btn" is a full button. It also ships themes, so one click restyles the entire page.

  1. Themes: find TODO SILVER S1. Copy the Halloween line twice. Change one copy to value="valentine" / aria-label="Valentine" and the other to value="cyberpunk" / aria-label="Cyberpunk". The value must match a theme name in frameworks.css exactly, all lowercase.
  2. Cards: find TODO SILVER S2. Copy the whole Ring Toss card (from <div class="card down to its closing </div>) twice. Make one about the Fun House and one about the Safety Inspector. Give each a different badge (badge-accent, badge-info) and button (btn-secondary, btn-accent).
  3. One more component: find TODO SILVER S3 and paste in one of the starter snippets there.

Done when: there are 6 theme buttons and each one restyles the whole page, there are 3 booth cards side by side, and your extra component shows up and changes color with the theme.

Gold: Animate.css (3 tickets each)

Animate.css is a library of ready-made animations. Add animate__animated plus an animation name and it plays. Browse them all at animate.style

  1. Open fun-house/funhouse.js and do steps G1 and G2 inside the click handler.
  2. You do not need to change any HTML for Gold. The three buttons below already have class="prize".

Done when: clicking any prize plays an animation, and clicking the same prize again plays it again (not just the first time).

Bonus: The Framework Tour (5 tickets per team)

  1. Open fun-house/tour.html in your browser and in your editor. It has a plain Ring Toss card.
  2. Pick ONE framework you have never used. Uncomment its <link> line in tour.html.
  3. Open that framework's card docs (links are in tour.html) and add its classes so the card looks like a real card.
  4. Write down one thing you liked and one thing you did not. You will tell the class.

Done when: tour.html shows the Ring Toss card styled by the new framework, and your team can name one like and one dislike.

  • Bootstrap (getbootstrap.com): the classic. Components first, huge community.
  • Pico.css (picocss.com): "classless". Write plain HTML and it already looks good.
  • Bulma (bulma.io): component framework with no JavaScript at all.
  • shadcn/ui (ui.shadcn.com): React components you copy into your own project. It needs React, so it will not work in tour.html. Read its Card page and compare it to DaisyUI instead.
