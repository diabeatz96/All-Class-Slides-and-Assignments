Getting started (one driver, two navigators)

  1. Driver: open fun-house/index.html in VS Code. Bronze and Silver happen in this file. Gold is in fun-house/funhouse.js.
  2. Edit and save. This page updates by itself, no refresh needed.
  3. Navigators: keep the docs open (links in every section) and read the class names out loud to the driver.
  4. Do the tickets in order. Bronze: follow the cheat sheet in the TODO BRONZE comment. Silver and Gold: each has a yellow "How to earn" box on this page with the exact code, and a TODO comment in the file marks where it goes.
  5. A class did nothing? Check the spelling: Tailwind ignores names it does not know, with no error. bg-teal-500 works; bg-teal does not.

How to earn Silver

First, decode the Ring Toss card

DaisyUI classes build the component. Tailwind classes (like w-72) tweak it. Both live in the same class="...".

ClassFromWhat it does
cardDaisyUIMakes the box a card (rounded corners, layout)
card-bodyDaisyUIAdds the padding inside the card
card-titleDaisyUIBig bold heading for the card
card-actions justify-endDaisyUI + TailwindA row for buttons, pushed to the right
badge badge-secondaryDaisyUIThe little "HOT" pill. badge = the shape, badge-secondary = its color
btn btn-primaryDaisyUIA full button. btn = the shape, btn-primary = its color
w-72TailwindWidth (72 × 4px = 288px)
bg-base-100DaisyUI colorThe theme's "page background" color, so it changes with the theme
shadow-xlTailwindA big drop shadow

The pattern: a base class (btn, badge, alert) plus an optional color (-primary, -secondary, -accent, -neutral, -info, -success, -warning, -error) and size (-xs, -sm, -lg, -xl). So btn btn-accent btn-lg is a large accent-colored button. badge-primary badge-accent badge-warning

Gold: Animate.css

Animate.css is a library of ready-made animations. Add animate__animated plus an animation name and it plays. Warm up in this HTML file, then finish in fun-house/funhouse.js.

WIN!

How to earn Gold

First, decode the bouncing WIN!

ClassWhat it doesRequired?
animate__animatedThe ON switch. Without it, nothing moves.Yes, always
animate__bounceWhich animation to playYes, exactly one
animate__infiniteRepeat forever (or animate__repeat-2, animate__repeat-3)Optional
animate__slowSpeed: animate__slower, animate__slow, animate__fast, animate__fasterOptional
animate__delay-1sWait before starting (-2s, -3s ... up to -5s)Optional

Every class starts with animate__ (two underscores). Names are case-sensitive: rubberBand works, rubberband does nothing. Good ones to try: tada rubberBand jello heartBeat wobble swing flip headShake bounceIn zoomIn. Full list with previews: animate.style.

Warm-up (HTML only, 1 minute)

Find TODO GOLD warm-up in this file. On the WIN! line, change one class and save:

before:  class="animate__animated animate__bounce animate__infinite animate__slow ..."
after:   class="animate__animated animate__rubberBand animate__infinite animate__slow ..."

Check: WIN! stretches instead of bouncing. Now you know animations are just classes.

Step 1: play an animation on click (in funhouse.js)

The prizes have no animation classes yet. We want JavaScript to add them when you click. That is what prize.classList.add(...) does: it is like typing those classes into the HTML, live. Open fun-house/funhouse.js, find TODO GOLD step 1, and uncomment the line:

prize.classList.add('animate__animated', 'animate__tada');

Check: click Teddy Bear and it does a tada. Click it again... nothing. On to step 2.

Step 2: make it replay

After the first click the button still has the classes, so the browser thinks the animation is done. We take them off when the animation ends, so the next click can add them again. Find TODO GOLD step 2 and uncomment the three lines:

prize.addEventListener('animationend', () => {
  prize.classList.remove('animate__animated', 'animate__tada');
}, { once: true });

Check: every click on any prize plays the tada again.

Bonus: a different animation per prize

Add data-anim="jello" (any name) to each prize button in this file. The bottom of funhouse.js shows how to read it.

Stuck? Nothing moves → check for two underscores and the exact capital letters. Red text in the Console (Cmd+Option+J) → a quote or bracket is missing on that line. Docs: Animate.css usage · classList on MDN

Bonus: The Framework Tour

Pick one framework you have never used, open its docs, and rebuild the Ring Toss card with it in a scratch file. Be ready to tell the class one thing you liked and one thing you did not.

  • Bootstrap: the classic. Components first, huge community.
  • shadcn/ui: React components you copy into your own project. Great fit for our React work.
  • Pico.css: "classless". Write plain HTML and it already looks good.
  • Bulma: component framework with no JavaScript at all.

Fastest way to try one: make a new tour.html outside this project, paste the framework's CDN <link> from its "Getting started" page into the <head>, then paste its card example into the body.
