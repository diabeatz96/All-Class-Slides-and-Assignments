# CSC 436, Week 5, Tuesday Sep 22: Review

Interactive review deck covering components, JSX, props, state, events, and conditional rendering, with a bug hunt and the Tip Splitter review lab.

## Run it

    npm install
    npm run dev

Open the printed URL (usually http://localhost:5173), then F11 for full screen.

## Presenting

- Right arrow, space, Page Down: next slide
- Left arrow, Page Up: previous slide
- Home: first slide
- N: toggle the instructor note strip
- Click a progress bar segment to jump

Slides live in `src/Deck.jsx`. Shared theme and helpers are in `src/ui.jsx`.

## Slides

1. Cold open: one tiny app that uses everything
2. Component tree explorer
3. JSX rules, spot the error (5 cases)
4. Props live editor
5. Prop, state, or derived? sorting game
6. useState and the snapshot rule
7. Events and controlled inputs
8. Conditional rendering recap and the 0 trap
9. Bug hunt (5 bugs)
10. Review lab: Tip Splitter (Bronze / Silver / Gold / Bonus)
11. Close quiz

ESM throughout. No require() or module.exports.
