## Quick start

    cd tue-node-express && npm install && npm run dev      # deck
    cd examples/recipe-box-api && npm install && npm run oops   # first live demo (crashes on purpose)

Decks: arrow keys to move, N for instructor notes, F11 for full screen. All deck demos run offline.
Requires Node 20.19 or newer.
