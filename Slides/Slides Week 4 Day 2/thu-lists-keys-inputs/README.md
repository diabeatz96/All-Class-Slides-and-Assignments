# CSC 436, Week 5, Thursday Sep 24: Mission 3, Lists, Keys, Controlled Inputs

Interactive deck. Theme: building a playlist. Ends with the Build Your Playlist assignment.

## Run it

    npm install
    npm run dev

Open the printed URL (usually http://localhost:5173), then F11 for full screen.

## Presenting

- Right arrow, space, Page Down: next slide
- Left arrow, Page Up: previous slide
- Home: first slide
- N: toggle the instructor note strip
- Click a progress bar segment to jump

Slides live in `src/Deck.jsx`. Shared theme and helpers are in `src/ui.jsx`.

## Slides

1. Title, live add-a-song list
2. map: array of data to array of elements
3. Keys and the index-key bug (live demo with inputs)
4. Controlled input plus a form with onSubmit
5. Adding: push vs spread
6. Removing: filter
7. Updating one item: map plus spread
8. Derived lists: search
9. Progression: hardcoded list to working playlist in four stages
10. Target build: Playlist Builder
11. Assignment: Build Your Playlist (Bronze / Silver / Gold / Bonus)
12. Close quiz

ESM throughout. No require() or module.exports.
