SCREENCAP SLOTS: Tuesday Nov 3, Mission 11 "Assemble the Crew"

How to add your own screencaps
1. Save an image into this folder (public/caps) using the exact slot name below.
2. jpg, png, webp and gif all work. The deck tries .jpg first, then .png, .webp, .gif.
3. 16:9 images look best. They are cropped to fill the frame.
4. Refresh the deck. Until an image exists, the slot shows a parchment placeholder
   with its file name, so the deck works fine without any images.
